# ralton.dev

Tools and apps I build for my own use, kept public in case they solve a problem for someone else too.

Most of these run in my homelab or grew out of my day-to-day work. They are built for one user first, so expect opinionated defaults — but everything here is free to use, fork or borrow from.

## Apps

| Repo | What it does |
| --- | --- |
| [finance-planner](https://github.com/ralton-dev/finance-planner) | Plan savings toward upcoming payments: how much to set aside each month per goal, and what is left over, across accounts and shared households. |
| [sourdough-planner](https://github.com/ralton-dev/sourdough-planner) | Plan one sourdough batch and split it into loaves, rolls and pizza. |
| [sudoku_puzzler](https://github.com/ralton-dev/sudoku_puzzler) | 9x9 sudoku generator, rater and solver, with a playable web app and technique training. |
| [url_utilities](https://github.com/ralton-dev/url_utilities) | Headless URL shortener with QR code generation. |
| [url_utilities_admin](https://github.com/ralton-dev/url_utilities_admin) | Admin UI for `url_utilities`. |
| [discord_github_docs_bot](https://github.com/ralton-dev/discord_github_docs_bot) | Discord bot that answers questions about a project from its own code and docs, with citations. |

## Infrastructure tools

| Repo | What it does |
| --- | --- |
| [aws-network-atlas](https://github.com/ralton-dev/aws-network-atlas) | Scans AWS accounts read-only and renders an interactive, committable network and security diagram. |
| [tf-import-blocks](https://github.com/ralton-dev/tf-import-blocks) | Generates Terraform `import` blocks from a state file, with the correct import id per resource type. |
| [zfs_exporter_image](https://github.com/ralton-dev/zfs_exporter_image) | Multi-arch container image of the `pdf/zfs_exporter` Prometheus exporter. |
